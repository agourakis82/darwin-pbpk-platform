# DARWIN: Mudança de Paradigma em Farmacocinética

## Visão Geral

Darwin não é apenas uma ferramenta. É uma **prova de mudança de paradigma** - simultaneamente:
- **Ferramenta**: PBPK que modela complexidade real
- **Comunidade**: Para "outsiders" e gifted marginalizados
- **Movimento**: Pela democratização do conhecimento científico

## O Problema Central

A farmacocinética mainstream ignora sistematicamente:
1. **Heterogeneidade** - trata tecidos como "well-stirred"
2. **Variação temporal** - trata parâmetros como constantes
3. **Variabilidade individual** - usa "one-size-fits-all"
4. **Influências ambientais** - ignora campos EM, ciclos solares

### Evidências do Problema
- Paper Nature 2023: Ciência cada vez MENOS disruptiva
- Paper Biochem Pharmacol 2019: Well-stirred model é admitidamente falso
- NNT de drogas comuns: 50-200 (maioria não se beneficia)
- 106.000 mortes/ano por reações adversas (EUA)
