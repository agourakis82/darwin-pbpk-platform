# DARWIN MANIFESTO

## A Ciência Parou de Ser Disruptiva

> "Papers são cada vez MENOS disruptivos" - Nature 2023

A ciência moderna está presa em:
- **Publicar ou perecer** → Incrementalismo seguro
- **Peer review** → Gatekeeping por "especialistas"
- **Grants** → Conservadorismo de comitês
- **Hierarquia** → Novatos devem ser deferentes

## O Que Ignoramos Por Conveniência

### 1. O Sangue Não É Água
- Fluido não-Newtoniano
- Viscosidade varia 10-20x com shear rate
- Formação de rouleaux
- Eritrócitos são sistemas dinâmicos

### 2. Nada É Constante
- Hematócrito varia ao longo do dia
- Proteínas plasmáticas variam
- Fluxo sanguíneo varia
- Expressão enzimática varia
- **MAS tratamos tudo como constante**

### 3. O Cérebro Não É Um Compartimento
- BBB é heterogênea por região
- Sistema glinfático (descoberto em 2012!)
- Clearance cerebral depende de sono
- **MAS usamos Kp_brain único**

### 4. O Feto Não É Um Adulto Pequeno
- Circulação radicalmente diferente
- Shunts que não existem no adulto
- Hemoglobina diferente
- Enzimas imaturas
- **MAS extrapolamos de adultos**

### 5. O Ambiente Afeta Tudo
- Campos geomagnéticos correlacionam com eventos cardíacos
- Ciclo solar correlaciona com saúde
- Hemoglobina é paramagnética
- **MAS fingimos que não existe**

## Por Que Ignoramos?

1. **Não era conveniente** - equações ficavam complexas
2. **Não era exigido** - reguladores aceitavam simplificações
3. **Não era possível** - computação era limitada
4. **Não era incentivado** - papers simples eram aceitos

## O Que Mudou

### Computação
- Simulações massivas são baratas
- Qualquer equação pode ser resolvida numericamente
- Machine learning aproxima funções arbitrárias

### Dados
- Genômica, proteômica, metabolômica públicos
- Wearables gerando dados fisiológicos
- Bases de dados de parâmetros crescendo

### LLMs
- Síntese de conhecimento cross-domain
- Geração de código a partir de equações
- Extração de parâmetros de literatura
- **Equipe de pesquisa em uma conversa**

## A Estratégia Darwin

### Cavalo de Tróia
1. Frontend bonito e fácil ("Instagramável")
2. Por baixo: paradigma completamente diferente
3. Resultados melhores → adoção orgânica
4. Quando perceberem, já mudaram

### Para Quem?
- "Outsiders" do sistema acadêmico
- Gifted marginalizados por não "jogar o jogo"
- Pesquisadores frustrados com incrementalismo
- Clínicos que sabem que algo está errado

### Contra Quem?
- Ninguém (não atacamos frontalmente)
- Simplesmente oferecemos alternativa melhor
- Deixamos os resultados falarem
