# LIVER VASCULAR ARCHITECTURE: The Dual Blood Supply

## 1. Overview: Why the Liver is Unique

The liver is the ONLY organ with **dual blood supply**:
1. **Hepatic Artery** (25% of flow, 50% of O2)
2. **Portal Vein** (75% of flow, 50% of O2)

This creates unique pharmacokinetic considerations for drug distribution.

### 2.2 What the Portal Blood Carries

| Component | Concentration | Source |
|-----------|---------------|--------|
| Glucose | High (postprandial) | Gut absorption |
| Amino acids | Variable | Protein digestion |
| Short-chain FA | Moderate | Colonic fermentation |
| Bilirubin | Conjugated | Spleen (RBC breakdown) |
| Ammonia | 0.1-0.5 mM | Gut bacteria, protein |
| **ORAL DRUGS** | **HIGH** | **GI absorption** |
| Bacterial toxins | Low | Gut translocation |
| Hormones | Insulin, GLP-1 | Pancreas, gut |

```
        ├──► Splenic Artery

                    │

                                │
                          ┌─────┴─────┐
                          │           │
                    LEFT HEPATIC   RIGHT HEPATIC
                      ARTERY         ARTERY
                          │           │
                          └─────┬─────┘
                                │
                          TO SINUSOIDS
```

### 3.2 Hepatic Arterial Buffer Response (HABR)

**Critical for drug delivery during portal flow changes:**

```
Normal State:
  Portal Vein:    75% of flow
  Hepatic Artery: 25% of flow

Portal Flow ↓ (e.g., portal thrombosis):
  Portal Vein:    ↓ (reduced)
  Hepatic Artery: ↑ (compensatory increase!)

This is mediated by:
  • Adenosine washout (↓ portal flow = ↑ adenosine = ↑ HA dilation)
  • Maintains oxygen delivery
  • Affects drug extraction ratio!
```

### 4.2 Key Features for Drug Distribution

| Feature | Description | PK Implication |
|---------|-------------|----------------|
| **Fenestrae** | 100-150 nm pores in endothelium | Free drug and small proteins pass |
| **No basement membrane** | Unlike other capillaries | Direct hepatocyte access |
| **Space of Disse** | Perisinusoidal space | Drug reservoir, stellate cells |
| **Slow flow** | ~400-800 μm/s | Maximizes extraction time |
| **Kupffer cells** | ~15% of liver cells | Phagocytosis, immune, drug uptake |
| **Stellate cells** | In Space of Disse | Vitamin A storage, fibrosis |

### 4.3 Fenestrae: The Open Windows

```
COMPARISON OF CAPILLARY TYPES:

1. CONTINUOUS (muscle, brain):
   ┌────────────────────────────────┐
   │████████████████████████████████│  ← Tight junctions
   └────────────────────────────────┘
   Passage: Only lipophilic drugs

2. FENESTRATED (kidney, endocrine):
   ┌────○────○────○────○────○────○──┐
   │████○████○████○████○████○████○██│  ← Small pores with diaphragm
   └────○────○────○────○────○────○──┘
   Passage: Small molecules, some proteins

3. SINUSOIDAL (liver, spleen, bone marrow):
   ┌──○───○───○───○───○───○───○───○─┐
   │██○███○███○███○███○███○███○███○█│  ← Large fenestrae, NO diaphragm
   └──○───○───○───○───○───○───○───○─┘
   Passage: Almost everything except blood cells!
   
   Fenestrae diameter: 100-150 nm
   Covers: 6-8% of surface
   Allows: Albumin (7 nm), lipoproteins, drugs
```

## 7. Blood Flow Quantification

### 7.1 Normal Values

| Parameter | Value | Notes |
|-----------|-------|-------|
| Total hepatic blood flow | 1500 mL/min | 25% of cardiac output |
| Portal vein flow | 1050-1200 mL/min | 75% of hepatic flow |
| Hepatic artery flow | 300-450 mL/min | 25% of hepatic flow |
| Liver weight | 1500 g | 2% body weight |
| Flow per gram | ~1 mL/min/g | Very high perfusion |

### 7.2 Flow Changes in Disease

```
CIRRHOSIS:
┌─────────────────────────────────────────────────────┐
│                                                     │
│  Portal vein flow: ↓ (resistance ↑)                │
│  Hepatic artery: ↑ (HABR compensation)             │
│  Portal pressure: ↑↑ (>12 mmHg)                    │
│                                                     │
│  Drug PK changes:                                   │
│  • Extraction ratio ↓ (reduced hepatocyte mass)    │
│  • Bioavailability ↑ (portosystemic shunts)        │
│  • Half-life ↑ (reduced clearance)                 │
│                                                     │
└─────────────────────────────────────────────────────┘

HEART FAILURE (Congestive Hepatopathy):
┌─────────────────────────────────────────────────────┐
│                                                     │
│  Hepatic vein pressure: ↑ (back pressure)          │
│  Sinusoidal congestion: ↑                          │
│  Portal flow: ↓ (reduced cardiac output)           │
│                                                     │
│  Drug PK changes:                                   │
│  • Hepatic clearance ↓                             │
│  • Vdss may change (edema)                         │
│  • Protein binding may change                      │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## 8. Implications for Drug Distribution (Kp)

### 8.1 How Vascular Architecture Affects Kp

```
DRUG ARRIVING AT LIVER:

1. FROM PORTAL VEIN (oral drugs):
   • Concentrated (first absorption)
   • Mixed with nutrients
   • Direct exposure to Zone 1 hepatocytes
   • Subject to first-pass extraction

2. FROM HEPATIC ARTERY (IV drugs):
   • Systemic concentration
   • O2-rich blood
   • Enters at sinusoidal level
   • No first-pass for recirculating drug

SINUSOIDAL EXTRACTION:
   
   Drug in ──► │ SINUSOID │ ──► Drug out
               │          │
               │ fenestrae│
               │    ↓     │
               │ ┌──────┐ │
               │ │DISSE │ │
               │ │SPACE │ │
               │ └──┬───┘ │
               │    ↓     │
               │HEPATOCYTE│
               │ ┌──────┐ │
               │ │ UPTAKE│ │ ◄── Active + passive
               │ │BINDING│ │ ◄── Proteins, lipids, phospholipids
               │ │METAB  │ │ ◄── CYP450, conjugation
               │ │EFFLUX │ │ ◄── BCRP, MRP, P-gp
               │ └──────┘ │
```

### 8.2 Extraction Ratio and Kp

```
EXTRACTION RATIO (E):

E = (C_in - C_out) / C_in

HIGH EXTRACTION (E > 0.7):
  • Examples: Propranolol, Lidocaine, Morphine
  • Clearance ≈ Blood flow (flow-limited)
  • Bioavailability ↓ (first-pass)
  • Kp affected by flow changes

LOW EXTRACTION (E < 0.3):
  • Examples: Warfarin, Diazepam, Theophylline
  • Clearance ≈ fu × CLint (capacity-limited)
  • Bioavailability ~100%
  • Kp affected by binding and enzyme changes

INTERMEDIATE EXTRACTION:
  • Both flow and capacity matter
  • Complex PK interactions
```

## 9. Summary: Vascular Architecture Key Points

```
┌─────────────────────────────────────────────────────────────────┐
│                     LIVER VASCULATURE                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. DUAL SUPPLY: Portal (75%) + Arterial (25%)                 │
│     → Oral drugs see liver FIRST (first-pass)                  │
│     → IV drugs distributed before liver                         │
│                                                                 │
│  2. SINUSOIDS: Unique fenestrated capillaries                  │
│     → Free passage of drugs and proteins                        │
│     → Direct hepatocyte access (no basement membrane)           │
│     → Slow flow maximizes extraction                            │
│                                                                 │
│  3. ZONATION: Periportal → Centrilobular gradient              │
│     → CYP450 highest in Zone 3                                 │
│     → Oxygen gradient affects metabolism                        │
│     → Zone-specific drug toxicity                               │
│                                                                 │
│  4. LYMPHATICS: 25-50% of body lymph from liver                │
│     → Alternative route for lipophilic drugs                    │
│     → Can bypass first-pass metabolism                          │
│                                                                 │
│  5. FLOW CHANGES: Disease alters everything                    │
│     → Cirrhosis: ↓ extraction, ↑ bioavailability               │
│     → Heart failure: ↓ clearance                                │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
