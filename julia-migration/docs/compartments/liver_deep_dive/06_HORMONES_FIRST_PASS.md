## 3. First-Pass Metabolism: The Oral Drug Challenge

### 3.1 Definition and Concept

```
FIRST-PASS EFFECT (Presystemic Elimination):

Drug metabolism BEFORE reaching systemic circulation.

ORAL DRUG JOURNEY:
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   ORAL DOSE                                                     │
│      │                                                          │
│      ▼                                                          │
│   STOMACH (minimal absorption for most drugs)                   │
│      │                                                          │
│      ▼                                                          │
│   SMALL INTESTINE                                               │
│      │                                                          │
│      ├──► INTESTINAL WALL (CYP3A4, P-gp, UGTs)                │
│      │    ↓                                                     │
│      │    Lost to GUT METABOLISM                                │
│      │                                                          │
│      ▼                                                          │
│   PORTAL VEIN                                                   │
│      │                                                          │
│      ▼                                                          │
│   LIVER (CYPs, UGTs, transporters)                             │
│      │                                                          │
│      ├──► Lost to HEPATIC METABOLISM                           │
│      │                                                          │
│      ▼                                                          │
│   SYSTEMIC CIRCULATION ◄── This is what we measure as "F"      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

BIOAVAILABILITY (F):
F = Fraction of oral dose reaching systemic circulation

F = f_abs × f_gut × f_hepatic

Where:
  f_abs = Fraction absorbed from gut lumen
  f_gut = Fraction escaping gut wall metabolism
  f_hepatic = Fraction escaping hepatic metabolism

Example:
  f_abs = 0.90 (90% absorbed)
  f_gut = 0.50 (50% escapes gut CYP3A4)
  f_hepatic = 0.30 (30% escapes hepatic metabolism)
  
  F = 0.90 × 0.50 × 0.30 = 0.135 (13.5% bioavailability)
```

### 3.2 Hepatic Extraction Ratio

```
HEPATIC EXTRACTION RATIO (E):

E = (C_in - C_out) / C_in

Where:
  C_in = Drug concentration entering liver (portal + arterial)
  C_out = Drug concentration leaving liver (hepatic vein)

E represents the fraction of drug removed in ONE PASS through liver.


RELATIONSHIP TO HEPATIC CLEARANCE:

CL_hepatic = Q_hepatic × E

Where:
  Q_hepatic = Hepatic blood flow (~1.5 L/min)
  E = Extraction ratio

RELATIONSHIP TO FIRST-PASS:

f_hepatic = 1 - E

F_hepatic = 1 - E


CLASSIFICATION:
┌─────────────────────────────────────────────────────────────────┐
│ EXTRACTION │ E VALUE   │ F_hepatic │ CLEARANCE │ EXAMPLES      │
├────────────┼───────────┼───────────┼───────────┼───────────────┤
│ HIGH       │ > 0.7     │ < 30%     │ Flow-     │ Propranolol   │
│            │           │           │ limited   │ Morphine      │
│            │           │           │           │ Lidocaine     │
│            │           │           │           │ Verapamil     │
├────────────┼───────────┼───────────┼───────────┼───────────────┤
│ INTER-     │ 0.3-0.7   │ 30-70%    │ Mixed     │ Aspirin       │
│ MEDIATE    │           │           │           │ Codeine       │
│            │           │           │           │ Quinidine     │
├────────────┼───────────┼───────────┼───────────┼───────────────┤
│ LOW        │ < 0.3     │ > 70%     │ Capacity- │ Diazepam      │
│            │           │           │ limited   │ Theophylline  │
│            │           │           │           │ Warfarin      │
│            │           │           │           │ Phenytoin     │
└────────────┴───────────┴───────────┴───────────┴───────────────┘
```

### 3.3 The Well-Stirred Model

```
WELL-STIRRED MODEL (Most commonly used):

Assumptions:
  • Liver is one homogeneous compartment
  • Drug instantly equilibrates
  • Venous concentration = tissue concentration

Equation:

E = (fu × CLint) / (Q + fu × CLint)

Where:
  fu = Fraction unbound in blood
  CLint = Intrinsic clearance (enzyme capacity)
  Q = Hepatic blood flow

Rearranging for clearance:

CL = (Q × fu × CLint) / (Q + fu × CLint)


SPECIAL CASES:

1. HIGH EXTRACTION (CLint >> Q):
   CL ≈ Q (flow-limited)
   
   • Clearance approaches blood flow
   • Changes in enzyme activity don't matter much
   • Changes in blood flow DO matter
   • Changes in binding DON'T matter

2. LOW EXTRACTION (CLint << Q):
   CL ≈ fu × CLint (capacity-limited)
   
   • Clearance depends on enzyme activity
   • Changes in enzyme activity DO matter
   • Changes in blood flow DON'T matter
   • Changes in binding DO matter


┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  CLINICAL IMPLICATIONS:                                         │
│                                                                 │
│  HIGH EXTRACTION DRUGS (Propranolol):                          │
│  • Liver disease: ↑ bioavailability (shunting)                 │
│  • Heart failure: ↓ clearance (↓ flow)                         │
│  • CYP inhibitors: Minor effect                                 │
│                                                                 │
│  LOW EXTRACTION DRUGS (Warfarin):                              │
│  • Liver disease: Variable (↓ enzymes vs ↓ protein)           │
│  • Heart failure: Minimal effect                                │
│  • CYP inhibitors: MAJOR effect (↑ levels)                     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 3.5 First-Pass in Liver Disease

```
LIVER DISEASE AND FIRST-PASS:

CIRRHOSIS:
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  TWO OPPOSING EFFECTS:                                          │
│                                                                 │
│  1. ↓ Metabolic capacity (fewer functioning hepatocytes)       │
│     → ↓ E → ↑ F                                                │
│                                                                 │
│  2. PORTOSYSTEMIC SHUNTING (portal hypertension)               │
│     → Blood bypasses liver entirely                            │
│     → ↑ F independent of enzyme activity                       │
│                                                                 │
│  NET EFFECT for HIGH EXTRACTION drugs:                         │
│  • F increases dramatically (sometimes 2-3 fold)               │
│  • Must reduce oral doses                                       │
│                                                                 │
│  NET EFFECT for LOW EXTRACTION drugs:                          │
│  • Variable (depends on degree of enzyme loss)                 │
│  • Often: ↑ F due to ↓ protein binding (more free drug)       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

EXAMPLE - PROPRANOLOL IN CIRRHOSIS:
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  Normal:                                                        │
│  • E = 0.75 (75% removed on first pass)                        │
│  • F = 0.25 (25% bioavailability)                              │
│                                                                 │
│  Cirrhosis:                                                     │
│  • E = 0.40 (reduced metabolism + shunting)                    │
│  • F = 0.60 (60% bioavailability)                              │
│                                                                 │
│  Result: 2.4× increase in bioavailability                      │
│  Clinical: Start with LOWER doses!                             │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 4. Enterohepatic Circulation

### 4.1 Overview

```
ENTEROHEPATIC CIRCULATION (EHC):

A cycle where drug (or metabolite) is:
1. Excreted in bile → Intestine
2. Reabsorbed from intestine
3. Returns to liver via portal vein
4. Repeat

┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│                           LIVER                                 │
│                             │                                   │
│                   Drug/Conjugate                                │
│                             │                                   │
│                             ▼                                   │
│                           BILE                                  │
│                             │                                   │
│                             ▼                                   │
│                    GALLBLADDER/DUODENUM                        │
│                             │                                   │
│                             ▼                                   │
│                      SMALL INTESTINE                            │
│                             │                                   │
│           ┌─────────────────┼─────────────────┐                │
│           │                 │                 │                │
│           ▼                 ▼                 ▼                │
│     If conjugate:     Bacterial        Drug reabsorbed        │
│     β-glucuronidase   metabolism              │                │
│           │                 │                 │                │
│           ▼                 ▼                 │                │
│     FREE DRUG         Modified drug          │                │
│           │                 │                 │                │
│           └─────────────────┼─────────────────┘                │
│                             │                                   │
│                             ▼                                   │
│                      PORTAL VEIN                                │
│                             │                                   │
│                             ▼                                   │
│                           LIVER (back to start)                │
│                                                                 │
│  Some drug lost in FECES each cycle                            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 5. Summary: Hepatic Factors Affecting Drug PK

```
┌─────────────────────────────────────────────────────────────────┐
│           HEPATIC FACTORS AFFECTING DRUG DISPOSITION           │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  FIRST-PASS METABOLISM:                                         │
│  • CYP450 (especially CYP3A4)                                  │
│  • UGTs, SULTs                                                  │
│  • Affects oral bioavailability (F)                            │
│                                                                 │
│  TRANSPORTERS:                                                  │
│  • Uptake: OATP1B1/1B3, OCT1, NTCP                            │
│  • Efflux: P-gp, MRP2, BCRP, BSEP                             │
│  • Affects hepatic drug concentration (Kp)                     │
│                                                                 │
│  PROTEIN BINDING:                                               │
│  • Albumin (acids), α1-AGP (bases)                            │
│  • Affects free fraction for metabolism                        │
│                                                                 │
│  BLOOD FLOW:                                                    │
│  • High extraction: Flow-limited clearance                     │
│  • Liver disease: Shunting increases F                         │
│                                                                 │
│  BILE EXCRETION:                                                │
│  • MRP2, BCRP, P-gp for efflux to bile                        │
│  • Enterohepatic circulation prolongs half-life                │
│                                                                 │
│  HEPATIC HORMONES:                                              │
│  • Generally not major factor for drug PK                      │
│  • But drugs can affect hormone levels                         │
│  • And hormones can affect metabolizing enzymes                │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

LIVER Kp PREDICTION MUST CONSIDER:
  1. Passive partitioning (lipophilicity)
  2. Active uptake (transporter substrates)
  3. Active efflux (P-gp, BCRP substrates)
  4. Metabolic trapping (drug metabolized faster than can exit)
  5. Protein/phospholipid binding (acidic phospholipids!)
  6. Lysosomal trapping (basic drugs, liver has high lysosome content)
```
